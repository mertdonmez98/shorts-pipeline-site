Privacy Policy

Last updated: November 17, 2026

Who this app is for

Shorts Pipeline is a personal, single-user application built and operated by its owner for their own YouTube channel only. It does not collect, process, or store data belonging to any third party, and it is not intended for use by the general public.

Scopes of access requested

The app requests only the following OAuth scopes, and uses them solely for the owner's own YouTube channel:

  • youtube.upload — to upload videos to the owner's channel.
  • youtube.readonly — to read the list and status of the owner's own uploaded videos.
  • yt-analytics.readonly — to read view and retention statistics of the owner's own videos, used only to improve content quality.

The app does not modify or delete existing videos, and does not access any other Google account data. Aggregated statistics for the owner's own videos are stored privately by the owner and are never shared or sold.

How OAuth tokens are handled

OAuth access and refresh tokens are stored only on the owner's own machine and, for scheduled runs, as encrypted secrets in the owner's private GitHub repository (GitHub Actions). They are never shared with or sold to any third party, advertiser, or external service.

Aggregated statistics of the owner's own videos (views, likes, average view percentage) are stored in the same private repository and are used only to improve content quality.

Use of YouTube API Services

Shorts Pipeline uses YouTube API Services. By using this app, the owner acknowledges and agrees to be bound by the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access granted to this app can be revoked at any time via Google Account Permissions.
