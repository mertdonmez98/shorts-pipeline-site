Shorts Pipeline

A personal content tool for the Cosmos Bite YouTube channel

Shorts Pipeline finds trending space and science news from public sources, produces short vertical videos with AI-generated narration and openly licensed imagery, and uploads them to its owner's own YouTube channel using the YouTube Data API v3. It reads view and retention statistics of the owner's own videos via the YouTube Analytics API to improve content quality.

The tool is run by a single developer for their own channel only. It is not offered to other users, does not collect data from anyone else, and does not act on behalf of third parties.
